# v0.9.2 — Consolidate all solo-dev project files under `.solo-dev/`

## What changed

All files that solo-dev creates inside a user's project are now stored under `.solo-dev/` at the project root, instead of being scattered across `.claude/` and `docs/`. This keeps solo-dev's files clearly separated from the project's own files.

## Path changes

| Old path | New path |
|----------|----------|
| `.claude/solo-dev-state.json` | `.solo-dev/state.json` |
| `.claude/solo-dev.local.md` | `.solo-dev/config.local.md` |
| `docs/yaml/` | `.solo-dev/yaml/` |
| `docs/agents/memory/` | `.solo-dev/memory/` |
| `docs/product/` | `.solo-dev/product/` |
| `docs/specs/` | `.solo-dev/specs/` |
| `docs/contracts/` | `.solo-dev/contracts/` |
| `docs/demos/` | `.solo-dev/demos/` |
| `docs/qa/` | `.solo-dev/qa/` |
| `docs/spikes/` | `.solo-dev/spikes/` |
| `docs/showcase/` | `.solo-dev/showcase/` |

## Impact on existing projects

All projects that have already run `/solo-dev:init` must migrate their files to the new paths.

## Migration steps

### 1. Create `.solo-dev/` directory

```bash
mkdir -p .solo-dev
```

### 2. Move state and config files

```bash
# State file
[ -f .claude/solo-dev-state.json ] && mv .claude/solo-dev-state.json .solo-dev/state.json

# Config file
[ -f .claude/solo-dev.local.md ] && mv .claude/solo-dev.local.md .solo-dev/config.local.md
```

### 3. Move docs subdirectories

```bash
[ -d docs/yaml ]          && mv docs/yaml          .solo-dev/yaml
[ -d docs/agents/memory ] && mv docs/agents/memory  .solo-dev/memory
[ -d docs/product ]       && mv docs/product        .solo-dev/product
[ -d docs/specs ]         && mv docs/specs          .solo-dev/specs
[ -d docs/contracts ]     && mv docs/contracts      .solo-dev/contracts
[ -d docs/demos ]         && mv docs/demos          .solo-dev/demos
[ -d docs/qa ]            && mv docs/qa             .solo-dev/qa
[ -d docs/spikes ]        && mv docs/spikes         .solo-dev/spikes
[ -d docs/showcase ]      && mv docs/showcase       .solo-dev/showcase
```

### 4. Clean up empty docs/agents/ if now empty

```bash
[ -d docs/agents ] && rmdir docs/agents 2>/dev/null || true
```

### 5. Update .gitignore (if solo-dev files were gitignored)

If your `.gitignore` has entries like `docs/yaml/` or `.claude/solo-dev*`, update them:
```
# Old entries to remove:
# .claude/solo-dev-state.json
# .claude/solo-dev.local.md

# New entries (if you want to gitignore config):
.solo-dev/config.local.md
```

### State changes (`.solo-dev/state.json`)

No field changes — only the file location changed.

Update `plugin_version` to `0.9.2` after migration.

### Config changes (`.solo-dev/config.local.md`)

No schema changes — only the file location changed.

### YAML changes (`.solo-dev/yaml/`)

No schema changes — only the directory location changed.

## Verification

After migration:
1. Run `/solo-dev:status` — should show project status normally
2. Confirm `.solo-dev/state.json` exists and contains `plugin_version: "0.9.2"`
3. Confirm `.solo-dev/yaml/features.yaml` exists (if project had features)
4. Confirm old paths are gone: `ls .claude/solo-dev*` should show nothing
