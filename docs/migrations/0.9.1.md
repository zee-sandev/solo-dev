# v0.9.1 — XS Effort Tier, Loop Fixes, Parallel Phase 0+1, Model Tiers

## What changed

- Added `XS` effort tier (minimal pipeline for deletions, renames, config changes)
- Added `--chore` flag to `next-feature` to force XS classification
- Phase 0 (market-validator) now runs in parallel with Phase 1 (design loop) for M/L/XL features
- Design loop max reduced from 3 → 2 rounds
- Code Review loop max reduced from 3 → 2 rounds
- QA loop max reduced from 3 → 2 rounds
- Business Validation: added max 2 rounds + defer as must_fix on round 2
- Security Review: added max 3 rounds → human escalation (no auto-proceed)
- Final Acceptance: graduated response (fix → partial spec → human) instead of re-entering Design Loop
- Added Cumulative Round Guard: warn at >8 total rounds, escalate at >12
- Support agents (gap-checker, smoke-tester, drift-detector, memory-curator) default model changed to `claude-haiku-4-5-20251001`
- Roadmap Overview added to `--auto` mode pre-loop and `/status`
- Pre-Flight now shows effort suggestion with reason + override options
- XL features now block at Pre-Flight (must decompose or override) instead of just suggesting
- Added `/go` launcher command
- Added `/migrate` command

## Impact on existing projects

- State schema: new fields added (`total_rounds`, `auto_mode`, `auto_max_features`, `auto_features_shipped`, `auto_stop_requested`)
- Config: no breaking changes — new options are additive with safe defaults
- YAML: no schema changes
- Agent model overrides: support agents now default to Haiku — override in `solo-dev.local.md` if needed
